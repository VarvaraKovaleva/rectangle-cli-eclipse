# Rectangle CLI Calculator

Учебный консольный калькулятор для расчёта характеристик прямоугольника.
Приложение запрашивает длину и ширину фигуры, после чего позволяет
вычислить периметр, площадь, диагональ, длину описанной окружности
и радиус вписанной (для квадрата).

## Возможности

- Безопасный ввод вещественных чисел (защита от букв, пустых строк и отрицательных значений).
- Расчёт основных характеристик:
  - Периметр: `P = 2(a + b)`
  - Площадь: `S = a * b`
  - Диагональ: `d = √(a² + b²)`
  - Длина описанной окружности: `C = π * d`
  - Радиус вписанной окружности: `r = a / 2` (только для квадрата).
- Возможность ввода новых параметров без перезапуска программы.
- Форматирование вывода до 2 знаков после запятой.

## Как запустить

### Вариант 1. Через Eclipse (для разработки)

1. Импортируйте проект: `File → Import → General → Existing Projects into Workspace`.
2. Найдите класс `App.java` (`src/main/java/ru/oivt/rectanglecli/App.java`).
3. Нажмите правой кнопкой → **Run As → Java Application**.

### Вариант 2. Через консоль (сборка в JAR)

Если у вас установлен JDK 17+:

```bash
# Скомпилировать исходники
javac -d bin src/main/java/ru/oivt/rectanglecli/App.java src/main/java/ru/oivt/rectanglecli/model/*.java src/main/java/ru/oivt/rectanglecli/ui/*.java src/main/java/ru/oivt/rectanglecli/util/*.java

# Запустить
java -cp bin ru.oivt.rectanglecli.App
```

## Пример работы

### 1. Запуск и ввод параметров:

```bash
Rectangle CLI Calculator

Введите параметры прямоугольника:
a (длина): 10
b (ширина): 5
Прямоугольник создан!
```

### 2. Меню и расчёт периметра:

```bash
----------------------------------------
Параметры прямоугольника: a = 10.00, b = 5.00
----------------------------------------

Выберите действие:

1. Периметр P = 2(a + b)
   ...
2. Выход

Ваш выбор: 1

Периметр:
P = 2(a + b) = 2(10.00 + 5.00) = 30.00

Нажмите Enter, чтобы продолжить...
```

### 3. Обработка ошибки ввода:

```bash
Введите параметры прямоугольника:
a (длина): abc
Ошибка: нужно число (например 10 или 3.5). Повторите.
a (длина): -5
Ошибка: значение должно быть > 0. Повторите.
a (длина): 10
```

## Тестирование

Проект покрыт unit-тестами (JUnit 5) для проверки корректности вычислений:

testPerimeter() — проверка периметра.

testArea() — проверка площади.

testDiagonal() — проверка диагонали.

testIsSquare() — проверка определения квадрата.

Запуск тестов в Eclipse: правой кнопкой по RectangleTest.java → Run As → JUnit Test.
